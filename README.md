\# Identifying Fraudulent Credit Card Transactions Using Ensemble Learning



\## Project Structure

\- \*\*M1\*\* - Data Preprocessing

\- \*\*M2\*\* - Model Training (CatBoost + CNN)

\- \*\*M3\*\* - Application (Streamlit App)



\## Dataset

The dataset used is not included in this repo due to size limitations.  

Download it from Kaggle: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud  

Place the downloaded 'creditcard.csv' inside the 'M1/' folder.



\## Models Used

\- CatBoost Classifier

\- CNN (Convolutional Neural Network)



\## How to Run

1\. Download the dataset and place in 'M1/'

2\. Run 'M1\_Data\_Preprocessing.ipynb'

3\. Run 'M2/Catboost\_Model\_CCF\_V2.ipynb'

4\. Run the app: 'streamlit run M3/App.py'
